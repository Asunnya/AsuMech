## AsuMech 0.6

**AnoMech is now AsuMech.** Uninstall AnoMech from the plugin installer: AsuMech imports its settings
(relay, streaks, recent fights) the first time it starts. Only one of the two can be installed.

- **Learn mode:** guided lessons for each strat, step by step, with the strat's toolbox picture.
  Give each step's text and picture a thumbs up or down; a thumbs down asks what's wrong.
- **Report a problem** from inside a run (the bug button on the run bar): a solo run pauses while you
  write, and the run's details (fight, strat, time, positions, what just happened) go with it. No
  character name is sent. Scenario and strat requests no longer need a GitHub account.
- Your **best streak** shows beside your streak.
- Multiplayer uses the **AsuMech server** by default; the AnoMech server still works as a custom server.
